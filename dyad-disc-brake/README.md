# Disc Brake Thermal Sample

This sample Dyad package describes a lumped-parameter thermal model for a
disc brake assembly. The library contains reusable thermal primitives together
with a top-level system (`DiscBrakeThermal`) that connects rotor and pad thermal
masses, frictional heat generation, contact resistance, and convective cooling
to an ambient environment.

## Contents

- `dyad/` — Dyad source files defining types, connectors, components, and the
  complete brake assembly.
- `Project.toml` — Julia environment with dependencies needed to simulate the
  generated model in ModelingToolkit/DifferentialEquations.
- `Manifest.toml` — Placeholder. Generate a full manifest with
  `Pkg.instantiate()` when you first run the example.
- `src/` — Placeholder directory for Julia sources generated by the Dyad CLI.
- `test.jl` — Convenience script showing how to simulate the model once code has
  been generated.

## Usage

1. Compile the Dyad sources into Julia code, e.g.

   ```bash
   npx dyad compile dyad --output src/DiscBrakeThermal.jl
   ```

2. Activate the local Julia environment and run the example simulation:

   ```julia
   julia --project=. test.jl
   ```

The `test.jl` script constructs the `DiscBrakeThermal` system, simulates a
30-second braking transient, and plots the rotor and pad temperatures.
